Platform Capabilities

Everything you need to eliminate credential risk

A complete authentication and threat-awareness platform built on open FIDO2 standards.

FIDO2 / WebAuthn Passkeys
Asymmetric key pairs stored in the device's secure enclave. No passwords ever transmitted or stored.
Phishing-Resistant by Design
Credentials are cryptographically bound to the registered origin. Attackers cannot replay signatures across domains.
Proximity Token (caBLE)
FIDO2 Hybrid transport lets users authenticate using a Bluetooth-paired phone as a roaming hardware key.
Biometric Privacy
Touch ID, Face ID, and Windows Hello biometrics never leave the device. Only digital signatures reach the server.
SOC Audit Stream
Every authentication event, phishing block, and honeypot trigger is logged to a live security operations feed.
Honey-Token Active Defense
Decoy endpoints log and fingerprint attackers that attempt to access non-existent system key exports.
Student & Staff Portals
Role-separated access flows with distinct authentication policies for academic and administrative users.
Phishing Simulation Lab
Demonstrate live phishing attacks against password systems and cryptographic defense via passkeys — side by side.
